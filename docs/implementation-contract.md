## Root composition and defaults
Hono application at src/index.ts. Dependencies injected via createApp override for deterministic tests, production export uses real providers.
AppEnv uses generated Env bindings, optional runtime string vars, CLIENT_API_KEYS and TYPESAFE_API_KEY.
Config: JEV_PROVIDER workers-ai; CONFIDENCE_AUTO .9; CONFIDENCE_REVIEW .6; CACHE_TTL_SECONDS 3600 (>=60); UPSTREAM_TIMEOUT_MS 15000; BATCH_MAX_ITEMS 20; BATCH_CONCURRENCY 4; AUTH_ENABLED true; ENVIRONMENT production; CORS_ALLOWED_ORIGINS empty; LOG_INPUTS false. Config invalid =>503 CONFIG_ERROR. auth false requires environment development. Config parsing root.
Service per item: authenticate at route -> validate -> limit -> cache lookup/validate -> evaluate on miss -> await cache write (failure =>ERROR, keep good inference) -> route -> optional preset decoration -> exactly one completion log. Cache false no reads/writes. Cache results only JevResult; recompute decision on every hit. No shared memory cache or cross-request dedup. Return DecisionOutcome.
POST route errors JSON {error:{code,message,issues?}}. X-Request-ID response; Cache-Control no-store on all responses. X-Cache for inference (batch MIXED allowed). 429 Retry-After:60. Supported methods GET/POST/OPTIONS. Public /,/health. /health checks config/auth/provider prerequisites but does not infer.
HTTP streaming read cap 64KiB normal,1MiB batch before parsing; 415 content type,400 JSON,413 size,405 methods,404 paths. CORS preflight before auth, explicit-origin denial before model.
Tests must run in workerd with Vitest cloudflareTest plugin, injected provider for route tests and direct adapter mocks for contracts. Do not call real AI from CI. Unit tests can use ordinary vitest imports and exported functions. Root provides tests/helpers.ts exporting config defaults and sample fixtures.
